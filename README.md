# Student Fee Payment System

## Description

The Student Fee Payment System is a Java console-based application designed to help a school record and manage student fee payments.

The system allows the user to:
- Enter student fee details
- Enter the amount paid by each student
- Calculate the remaining balance
- Detect overpayments
- Determine the student's payment status
- Display a summary of total fees, payments, and balances

## Technologies Used

- Java
- Eclipse IDE
- GitHub

## Java Concepts Used

This application demonstrates:

- While loop
- For loop
- Do-while loop
- Ternary operator
- If statements
- Variables and data types
- Scanner class for user input

## How to Run the Application

1. Download or clone this repository from GitHub.
2. Open Eclipse IDE.
3. Import the project into Eclipse.
4. Open:
   
   `src → studentfeepayment... → FeePaymentSystem.java`

5. Right-click `FeePaymentSystem.java`.
6. Select **Run As → Java Application**.
7. The application will open in the Eclipse Console.
8. Follow the instructions displayed on the screen.

## Example Functions

The system can determine whether a student is:

- No Payment
- Partially Paid
- Fully Paid

It also calculates outstanding balances and identifies overpayments.

## Project Purpose

This project was developed as a Java programming assignment to demonstrate the practical use of loops, conditional statements, and the ternary operator in a real-world school fee management scenario.
