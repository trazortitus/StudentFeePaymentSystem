## Project Purpose

This project was created as part of a Java programming assignment to show how basic Java concepts can be used to solve a real-life problem. We chose a school fee payment system because it is a simple and practical way to keep track of how much each student is supposed to pay, how much they have paid, and what balance they still have.

While developing the system, we applied concepts such as loops, if statements, variables, the Scanner class, and the ternary operator. The project also helped us understand how these concepts work together to create a useful Java application rather than just using them in separate examples.
